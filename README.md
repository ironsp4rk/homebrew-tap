# ironsp4rk Homebrew Tap

This is a personal Homebrew tap for [ironsp4rk](https://github.com/ironsp4rk)'s projects.

## How do I install these formulae?

To add this tap to your Homebrew installation, run:

```bash
brew tap ironsp4rk/homebrew-tap
```

Once the tap is added, you can install any of the available formulae.

### Available Formulae

| Formula | Description | Install Command |
| :--- | :--- | :--- |
| **casc-cli** | CLI tool for Blizzard CASC archives | `brew install casc-cli` |

## Maintenance

The formulae in this repository are automatically updated and maintained via [cargo-dist](https://opensource.axo.dev/cargo-dist/) from their respective source repositories.

## Documentation
`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
